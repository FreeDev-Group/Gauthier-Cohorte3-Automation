# UC Review Past Feedback

## Description

This folder contains the execution evidence for the automated tests of the **Review Past Feedback** use case.

The test suite verifies that students can review surveys they have already completed and view the responses previously submitted.

The tests cover:

- Accessing the "My Completed Surveys" page
- Displaying the list of completed surveys
- Opening a completed survey
- Viewing previously submitted answers

## Folder Structure

### Screenshots

Contains screenshots captured during the execution of each test scenario.

### Report

Contains the HTML/JSON execution reports generated by Cypress and Mochawesome.

### Videos

Contains the complete recording of the automated test execution.

## Objective

To ensure that students can review their previously submitted survey responses according to the **Review Past Feedback** use case specification.

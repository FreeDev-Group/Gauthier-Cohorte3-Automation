# UC Provide Feedback

## Description

This folder contains the execution evidence for the automated tests of the **Provide Feedback** use case.

The test suite validates the student's ability to complete an available survey by navigating through the survey list, answering questions, and submitting feedback.

The tests cover:

- Accessing available surveys
- Opening a survey
- Viewing survey questions
- Completing survey responses
- Submitting feedback successfully

## Folder Structure

### Screenshots

Contains screenshots captured during the execution of the test scenarios.

### Report

Contains the HTML/JSON reports generated by Cypress and Mochawesome.

### Videos

Contains the complete recording of the automated test execution.

## Objective

To verify that students can successfully complete and submit surveys according to the **Provide Feedback** use case specification.

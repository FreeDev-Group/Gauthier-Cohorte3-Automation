# UC Login

## Description

This folder contains the execution evidence for the automated tests of the **Login** use case.

The test suite also includes the **Recover Password** scenarios, as password recovery is considered part of the authentication workflow.

The automated tests verify:

- Login page accessibility
- Invalid login attempts
- Validation messages
- Password recovery process
- Successful authentication
- Redirection to the Student Home page

## Folder Structure

### Screenshots

Contains screenshots captured during each test scenario.

### Report

Contains the HTML/JSON execution reports generated by Cypress and Mochawesome.

### Videos

Contains the complete video recording of the test execution.

## Objective

To validate the authentication workflow according to the **Login** use case specification.

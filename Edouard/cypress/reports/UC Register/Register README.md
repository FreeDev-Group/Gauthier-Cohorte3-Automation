# UC Register

## Description

This folder contains the execution evidence for the automated tests of the **Register (Create Account)** use case in the Student Survey App.

## Folder Structure

### Screenshots

Contains screenshots automatically captured by Cypress during the execution of each test scenario.

### Report

Contains the HTML/JSON test reports generated by Cypress and Mochawesome.

### Videos

Contains the video recording of the complete test execution.

## Objective

To verify that the user registration process behaves correctly according to the **Register** use case specification.
